# RootsWeb – School Website

RootsWeb is a responsive, modern, and dynamic school website designed to provide seamless communication between students, staff, and the public. Built using modern web technologies, RootsWeb delivers an informative and engaging experience, reflecting the institution’s values, mission, and services.

## ✨ Features

- 📚 Home page with welcome message and announcements
- 🏫 About page detailing the school’s mission and vision
- 📂 Academic programs and departments
- 📰 Blog/News section for updates and events
- 📞 Contact form with Google Maps integration
- 🖼️ Image gallery

## 🛠️ Technologies Used

- HTML5, CSS3, JavaScript
- Bootstrap 5
- PHP (backend)
- Responsive design principles

## 🚀 Getting Started

## 1. Clone the repository:
   git clone https://github.com/m1-ah/rootsweb.git
   
## 2. Open the project folder in your code editor or run it on a local server.

## 3. If using backend integration, configure your database or Firebase settings as needed.
